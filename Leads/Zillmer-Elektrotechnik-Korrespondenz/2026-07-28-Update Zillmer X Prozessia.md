Folgetermin zum Gespräch vom 21.07.2026 mit Dierk Biendarra. Sebastian stellt eine Prozessskizze vor, wie ein KI-Agent den Ausschreibungs-/Einkaufsprozess bei Zillmer unterstützen könnte.

## Prozessskizze (von Biendarra bestätigt, deckt sich mit dem im Meeting vom 21.07. Besprochenen)

1. Ausschreibung geht ein.
2. Falls Hersteller eindeutig genannt/erkennbar ist → direkter Preisvergleich.
3. Falls Hersteller nicht eindeutig ist → Agent recherchiert innerhalb eines definierten Rahmens von ca. 50 möglichen Herstellern (bewusst begrenzt, damit die Recherche nicht ausufert).
4. Nach der Recherche: Agent stellt selbstständig Preisanfragen an den Großhandel/die Hersteller (per E-Mail-Postfach-Anbindung).
5. Günstigstes Angebot bzw. Angebotsübersicht wird an Biendarra/Beteiligte weitergegeben.

Sicherheitsstufen-Ansatz: Start mit E-Mail-Entwürfen, die von Zillmer freigegeben werden, erst später (nach Vertrauensaufbau) automatischer Versand direkt an Hersteller.
