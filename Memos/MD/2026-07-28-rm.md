# rm

## Zusammenfassung
Shell-Kommandos zum Anlegen einer .env-Datei mit dem LEXOFFICE_API_KEY (Lexoffice API-Schlüssel im Klartext), inkl. chmod 600 zur Rechtevergabe. Wirkt wie ein Setup-/Debug-Snippet für eine Lexoffice-Integration.

## Vollständiger Inhalt
rm .env printf 'LEXOFFICE_API_KEY= wdD7H0EjgpyTyghjneB0TTys-L1A_pl3gulxHaymC8Vcq50j \n' > .env chmod 600 .env cat -et .env cat > .env << 'EOF' LEXOFFICE_API_KEY= wdD7H0EjgpyTyghjneB0TTys-L1A_pl3gulxHaymC8Vcq50j EOF chmod 600 .env ls -la .env cat .env
